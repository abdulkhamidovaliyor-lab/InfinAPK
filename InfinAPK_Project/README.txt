INFIN LOCAL APP — Android project

Готово:
- PIN-экран: пароль 0000, 4 индикатора, удаление цифры.
- Главная / Переводы / Платежи / История.
- Нижняя навигация фиксирована.
- История: операция 10 025 000.00 открывает детали.
- Детали: Квитанция -> экран квитанции.
- X на квитанции -> назад к деталям.
- Стрелка назад -> История.
- На главную -> Главная.
- Иконка приложения установлена.

СБОРКА APK В ANDROID STUDIO:
1. Распакуйте ZIP.
2. Android Studio -> Open -> выберите папку InfinAPK_Project.
3. Дождитесь Gradle Sync.
4. Build -> Build App Bundle(s) / APK(s) -> Build APK(s).
5. APK: app/build/outputs/apk/debug/app-debug.apk

Если Android Studio предложит установить Android SDK 35 — подтвердите установку.
